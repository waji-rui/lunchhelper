示例插件页面
本页由 plugins/Com.Example.Demo 注册，未修改主程序一行代码。

第三方插件只需提供一个 plugin.json（id / name / pages）与页面片段 HTML，放到 exe 同目录的 plugins/<你的id>/ 下即可被自动加载。页面复用宿主的 MD3 设计令牌与组件样式（.card / .text / .t / .s 等），不依赖任何额外 CSS。

需要交互逻辑时，在片段里放 data-plugin-init="globalFnName"，宿主会在注入后调用 window.globalFnName(sectionEl, pageObj)。
